# 8051-Development-Board & STM32

Documentation of microcontroller experiments and projects covering GPIO, UART, timers, interrupts, PWM, LCD interfacing, keypad interfacing, STM32 peripherals and IoT applications.

**Microcontrollers:** AT89S52 (8051), STM32 NUCLEO-F401RE  
**8051 Clock Frequency:** 11.0592 MHz  
**Programming Languages:** Embedded C

## NOTE:

8051 experiments use the AT89S52 microcontroller and Keil C51 compiler. STM32 experiments use the STM32 HAL libraries and STM32CubeMX-generated project configurations.

Task-specific hardware connections, source files, libraries and circuit diagrams are maintained in their respective experiment folders.

## CONCLUSION:

This repository documents embedded systems experiments and projects involving 8051 and STM32 microcontrollers, covering GPIO programming, timer interrupts, serial communication, peripheral interfacing, sensor integration and IoT-based applications.
